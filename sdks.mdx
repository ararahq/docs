Os SDKs são open source no [GitHub](https://github.com/ararahq) e falam com `https://api.ararahq.com` usando `Authorization: Bearer ara_live_...`. Para qualquer outra linguagem, use REST com a biblioteca HTTP padrão: [API Reference](/api-reference/introduction).

## Catálogo

| Linguagem | Pacote | Instalar | Versão e registro |
|---|---|---|---|
| [Node.js / TypeScript](/sdks/node) | `@ararahq/sdk` | `npm install @ararahq/sdk` | 2.0.0, npm |
| [Python](/sdks/python) | `ararahq-sdk` (import `arara_api_sdk`) | `pip install ararahq-sdk` | 2.0.0, PyPI |
| [PHP / Laravel](/sdks/php) | `ararahq/sdk` | `composer require ararahq/sdk` | 2.0.0, Packagist |
| [Java / Kotlin](/sdks/java) | `com.ararahq:arara-java-sdk` | `implementation("com.ararahq:arara-java-sdk:2.0.0")` | 2.0.0, GitHub Packages (não está no Maven Central; exige usuário e token do GitHub) |
| [Go](/sdks/go) | `github.com/ararahq/arara-go-sdk` | `go get github.com/ararahq/arara-go-sdk@latest` | v1.0.0, tag no GitHub |
| [Ruby](/sdks/ruby) | `ararahq` | `gem "ararahq"` | 1.0.0, RubyGems |

Cada página de linguagem traz instalação, o primeiro envio, tratamento de erros, retentativas, webhooks e limitações.

## Recursos por SDK

Recursos expostos pela versão publicada de cada SDK. Contatos, conversas, carteira, opt-outs e `auth.me` exigem chave de API com permissão ADMIN.

| Recurso | Node | Python | PHP | Java | Go | Ruby |
|---|---|---|---|---|---|---|
| Enviar mensagem | Sim | Sim | Sim | Sim | Sim | Sim |
| Consultar mensagem por id | Sim | Sim | Sim | Sim | Sim | Sim |
| Envio em lote | Sim | Sim | Sim | Sim | Sim | Sim |
| `Idempotency-Key` no envio | Sim | Sim | Sim | Sim | Sim | Sim |
| Templates | Sim | Sim | Sim | Sim | Sim | Sim |
| Campanhas | Sim | Sim | Sim | Sim | Sim | Sim |
| Contatos | Sim | Sim | Sim | Sim | Sim | Sim |
| Conversas | Sim | Sim | Sim | Sim | Sim | Sim |
| Carteira | Sim | Sim | Sim | Sim | Sim | Sim |
| Números | Sim | Sim | Sim | Sim | Sim | Sim |
| Smart links | Sim | Sim | Sim | Sim | Sim | Sim |
| Opt-outs | Sim | Sim | Sim | Sim | Sim | Sim |
| Usuário atual (`auth.me`) | Sim | Sim | Sim | Sim | Sim | Sim |

Webhook da organização e chaves de API: nenhum SDK gerencia, porque a API recusa esses endpoints com chave de API. Configure pelo [painel](https://app.ararahq.com/dashboard/webhooks).

O detalhe de cada limitação está na seção **Limitações conhecidas** da página de cada SDK. Para um recurso fora do SDK, chame a API direto com o mesmo header de autenticação.
