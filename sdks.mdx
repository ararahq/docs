A Arara mantém 6 SDKs open source no [GitHub](https://github.com/ararahq), além do CLI e do MCP server. Todos falam com `https://api.ararahq.com` usando `Authorization: Bearer ara_live_...`.

Esta página diz o que está **publicado** em cada registry. O código na branch `main` de alguns repositórios já tem mais recursos do que a versão publicada; quando for o caso, a página de cada SDK avisa.

## Cobertura por SDK

Recursos expostos pela versão que você instala hoje (Node, Python, PHP e Java na 1.8.1; Go e Ruby na `main`).

| Recurso | Node | Python | PHP | Java | Go | Ruby |
|---|---|---|---|---|---|---|
| Enviar mensagem | Sim | Sim | Sim | Sim | Sim | Sim |
| Templates | Sim | Parcial | Sim | Parcial | Parcial | Sim |
| Campanhas | — | Com defeito | — | Parcial | Sim | Sim |
| Contatos | — | — | — | — | Sim | Sim |
| Conversas | — | — | — | — | Sim | Sim |
| Carteira | — | — | — | — | Sim | Sim |
| Números | — | Parcial | — | — | Sim | Sim |
| Smart links | — | — | — | — | Sim | Sim |
| Usuário (`/users/me`) | Sim | Sim | Com defeito | Sim | Sim | Sim |
| Webhook da organização | Sim | Sim | Com defeito | — | Sim | Sim |
| Header de idempotência no envio | Sim | — | — | — | Sim | Sim |

"Parcial" e "Com defeito" estão detalhados na página de cada SDK, na seção **Limitações conhecidas**. Alguns métodos existem no SDK mas falham contra a API atual (por exemplo, criar API key e listar templates em SDKs tipados); a página de cada linguagem lista quais.

Para um recurso fora do SDK, chame a API direto com o mesmo header de autenticação.

## O que todos os SDKs fazem

- Enviam `Authorization: Bearer <sua chave>` em toda requisição.
- Usam `https://api.ararahq.com` como base padrão, configurável.
- Retentam automaticamente falha de rede e respostas 5xx com backoff exponencial. Node, PHP, Java, Go e Ruby também retentam 429 respeitando `Retry-After`.
- Convertem erro HTTP em exceção (ou `error`, no Go) com status e corpo da resposta.

<Warning>
  O retry automático também reenvia `POST /v1/messages` quando a API responde 5xx. Se o seu SDK aceita chave de idempotência no envio (Node, Go, Ruby), passe sempre uma. Nos outros, considere desligar o retry para envios.
</Warning>

## Exemplo lado a lado

Mesma operação: enviar template com header de mídia e 2 variáveis.

<CodeGroup>
```typescript Node.js
import { NodeSDK } from '@ararahq/sdk';

const sdk = new NodeSDK({ apiKey: process.env.ARARA_API_KEY! });

await sdk.messages.send({
  receiver: 'whatsapp:+5511999999999',
  templateName: 'fatura_disponivel',
  templateVariables: [
    'https://meusite.com/fatura.pdf', // header (mídia)
    'João',                            // {{1}}
    'Janeiro',                         // {{2}}
  ],
});
```

```python Python
from arara_api_sdk import AraraClient
from arara_api_sdk.models.message import SendMessageRequest

with AraraClient(api_key="ara_live_xxx") as client:
    client.messages.send(SendMessageRequest(
        receiver="whatsapp:+5511999999999",
        template_name="fatura_disponivel",
        template_variables=[
            "https://meusite.com/fatura.pdf",
            "João",
            "Janeiro",
        ],
    ))
```

```php PHP
use Arara\Arara;
use Arara\Config;

$sdk = new Arara(new Config(apiKey: 'ara_live_xxx'));

$sdk->messages->send(
    receiver: 'whatsapp:+5511999999999',
    templateName: 'fatura_disponivel',
    variables: [
        'https://meusite.com/fatura.pdf',
        'João',
        'Janeiro',
    ],
);
```

```java Java
import com.ararahq.arara.sdk.Arara;
import com.ararahq.arara.sdk.models.SendMessageRequest;
import java.util.List;

Arara arara = Arara.builder().apiKey("ara_live_xxx").build();

arara.getMessages().send(
    SendMessageRequest.builder()
        .receiver("whatsapp:+5511999999999")
        .templateName("fatura_disponivel")
        .templateVariables(List.of(
            "https://meusite.com/fatura.pdf",
            "João",
            "Janeiro"
        ))
        .build()
);
```

```go Go
client, err := arara.NewClient(os.Getenv("ARARA_API_KEY"))
if err != nil {
    log.Fatal(err)
}

_, err = client.Messages.Send(context.Background(), &arara.SendMessageRequest{
    Receiver:     "whatsapp:+5511999999999",
    TemplateName: "fatura_disponivel",
    TemplateVariables: []string{
        "https://meusite.com/fatura.pdf",
        "João",
        "Janeiro",
    },
})
```

```ruby Ruby
require "arara"

client = Arara::Client.new(api_key: ENV.fetch("ARARA_API_KEY"))

client.messages.send(
  receiver: "whatsapp:+5511999999999",
  template_name: "fatura_disponivel",
  template_variables: [
    "https://meusite.com/fatura.pdf",
    "João",
    "Janeiro"
  ]
)
```
</CodeGroup>

**Padrão de mídia**: a URL da mídia (imagem, vídeo ou PDF) do header vai como **primeiro elemento** de `templateVariables`. As posições seguintes preenchem `{{1}}`, `{{2}}`... do corpo do template. O campo `media_url` ainda é aceito, mas está marcado como legado na API.
