O SDK PHP da Arara (`ararahq/sdk`, versão publicada 1.8.1) funciona em Laravel e PHP puro. Esta página mostra setup, envio síncrono, queue jobs e recebimento de webhooks com validação de assinatura.

<Note>
  **Requisitos:** PHP 8.2+, Laravel 10+. Compatível com 11.x e 12.x.
</Note>

## Instalação

```bash
composer require ararahq/sdk
```

## Configuração

Adicione as variáveis no `.env`:

```ini
ARARA_API_KEY=ara_live_xxx
ARARA_WEBHOOK_SECRET=whsec_xxx
```

O `ARARA_WEBHOOK_SECRET` é o secret do webhook da organização (quando gerado pela Arara, começa com `whsec_`). Você encontra na configuração de webhook do dashboard (https://app.ararahq.com).

Crie um Service Provider para registrar o SDK como singleton:

```php
// app/Providers/AraraServiceProvider.php
namespace App\Providers;

use Arara\Arara;
use Arara\Config;
use Illuminate\Support\ServiceProvider;

class AraraServiceProvider extends ServiceProvider
{
    public function register(): void
    {
        $this->app->singleton(Arara::class, function () {
            return new Arara(new Config(
                apiKey: config('services.arara.key'),
            ));
        });
    }
}
```

Registre em `config/app.php` (ou `bootstrap/providers.php` no Laravel 11+). O `baseUrl` padrão já é `https://api.ararahq.com`; se sobrescrever, não inclua `/v1`.

E adicione a chave em `config/services.php`:

```php
'arara' => [
    'key' => env('ARARA_API_KEY'),
    'webhook_secret' => env('ARARA_WEBHOOK_SECRET'),
],
```

## Enviando mensagem em Controller

```php
// app/Http/Controllers/OrderController.php
use Arara\Arara;

public function store(Request $request, Arara $sdk)
{
    $order = Order::create($request->validated());

    $sdk->messages->send(
        receiver: 'whatsapp:' . $order->customer->phone,
        templateName: 'confirmacao_pedido',
        variables: [
            $order->customer->first_name,
            $order->code,
            $order->total_formatted,
        ]
    );

    return response()->json($order, 201);
}
```

O `receiver` precisa estar no formato `whatsapp:+<DDI><número>`. Fora disso o SDK lança `Arara\Exceptions\ValidationException` antes de chamar a API. `send` devolve um `array` com `id` (`ara_msg_...`) e `status` inicial.

## Envio assíncrono com Queue

Em produção, envie de um job. Um cuidado: `send` do SDK 1.8.1 **não aceita** `Idempotency-Key`, e tanto o retry do SDK (5xx) quanto o retry do job podem reenviar a mesma mensagem. Para jobs, chame a API pelo `Http` do Laravel com uma chave derivada do pedido:

```php
// app/Jobs/SendOrderConfirmation.php
namespace App\Jobs;

use App\Models\Order;
use Illuminate\Bus\Queueable;
use Illuminate\Contracts\Queue\ShouldQueue;
use Illuminate\Foundation\Bus\Dispatchable;
use Illuminate\Support\Facades\Http;

class SendOrderConfirmation implements ShouldQueue
{
    use Dispatchable, Queueable;

    public int $tries = 4;

    public function __construct(public int $orderId) {}

    public function handle(): void
    {
        $order = Order::with('customer')->findOrFail($this->orderId);

        Http::withToken(config('services.arara.key'))
            ->withHeaders(['Idempotency-Key' => "order-confirmation-{$order->id}"])
            ->timeout(10)
            ->post('https://api.ararahq.com/v1/messages', [
                'receiver' => 'whatsapp:' . $order->customer->phone,
                'templateName' => 'confirmacao_pedido',
                'templateVariables' => [
                    $order->customer->first_name,
                    $order->code,
                    $order->total_formatted,
                ],
            ])
            ->throw();
    }

    public function backoff(): array
    {
        return [30, 120, 300];
    }
}
```

Dispare assim:

```php
SendOrderConfirmation::dispatch($order->id);
```

A API responde `202`. Repetir a mesma `Idempotency-Key` devolve a mensagem original, sem novo envio. Em `POST /v1/messages` isso vale mesmo se o payload mudar (a API não compara destinatário nem variáveis), então nunca reaproveite a chave para outra mensagem.

## Recebendo webhooks

Crie a rota:

```php
// routes/api.php
Route::post('/webhooks/arara', AraraWebhookController::class)
    ->name('webhooks.arara');
```

A Arara assina cada entrega com `X-Arara-Timestamp` (epoch em segundos) e `X-Arara-Signature` (`sha256=` + hex do HMAC-SHA256 de `{timestamp}.{corpo cru}` com o secret). O `WebhookUtils::verifySignature()` da 1.8.1 não inclui o timestamp e nunca bate; valide manualmente:

```php
// app/Http/Controllers/AraraWebhookController.php
namespace App\Http\Controllers;

use Illuminate\Http\Request;

class AraraWebhookController extends Controller
{
    private const TOLERANCE_SECONDS = 300;

    public function __invoke(Request $request)
    {
        $body = $request->getContent();
        $timestamp = (string) $request->header('X-Arara-Timestamp', '');
        $signature = (string) $request->header('X-Arara-Signature', '');
        $secret = config('services.arara.webhook_secret');

        $expected = 'sha256=' . hash_hmac('sha256', $timestamp . '.' . $body, $secret);
        $fresh = ctype_digit($timestamp) && abs(time() - (int) $timestamp) <= self::TOLERANCE_SECONDS;

        if (! $fresh || ! hash_equals($expected, $signature)) {
            abort(401, 'Invalid signature');
        }

        $payload = json_decode($body, true);
        $data = $payload['data'] ?? [];

        match ($payload['event'] ?? null) {
            'message.status_updated' => $this->handleStatus($data),
            'message.received' => $this->handleInbound($data),
            'conversation.needs_human' => $this->handleHandoff($data),
            default => null,
        };

        return response()->noContent();
    }

    private function handleStatus(array $data): void
    {
        // $data['id'] = ara_msg_... ; $data['status']: queued, sent, delivered, read, failed...
    }

    private function handleInbound(array $data): void
    {
        // $data['from'], $data['body'], $data['type'] (text | media)
    }

    private function handleHandoff(array $data): void
    {
        // o assistente de IA pediu humano: $data['conversationId'], $data['reason'], $data['summary']
    }
}
```

`hash_equals` compara em tempo constante. Não use `==`. Se a resposta não for 2xx, a Arara tenta de novo (30s, 2min, 15min, 1h, 4h), então o handler precisa aguentar o mesmo evento duas vezes. Use o header `X-Arara-Delivery-Id` como chave de dedupe.

<Warning>
  Rotas em `routes/api.php` já ficam fora da verificação de CSRF. Se registrar o webhook em `routes/web.php`, adicione o path ao `VerifyCsrfToken@except` (Laravel 10) ou a `validateCsrfTokens(except: [...])` em `bootstrap/app.php` (Laravel 11+).
</Warning>

## Broadcasting (Pusher / Reverb)

Pra ver mensagens em tempo real no admin:

```php
// app/Events/MessageStatusChanged.php
namespace App\Events;

use Illuminate\Broadcasting\Channel;
use Illuminate\Broadcasting\InteractsWithSockets;
use Illuminate\Contracts\Broadcasting\ShouldBroadcast;
use Illuminate\Foundation\Events\Dispatchable;

class MessageStatusChanged implements ShouldBroadcast
{
    use Dispatchable, InteractsWithSockets;

    public function __construct(public string $messageId, public string $status) {}

    public function broadcastOn(): Channel
    {
        return new Channel('arara.messages');
    }
}
```

E no `handleStatus`:

```php
broadcast(new MessageStatusChanged($data['id'], $data['status']));
```
