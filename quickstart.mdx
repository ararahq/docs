Ao fim desta página você terá enviado uma mensagem de WhatsApp pela API e consultado o status dela.

## Veja chegar no seu WhatsApp

Antes de configurar qualquer coisa, receba uma mensagem enviada pela API. Ela sai do número de demonstração da Arara e não exige conta.

A demonstração roda esta chamada, a mesma que você vai fazer com a sua chave. É um template de carrinho abandonado com [cobrança](/cobrancas):

```bash
curl -X POST https://api.ararahq.com/v1/messages \
  -H "Authorization: Bearer $ARARA_API_KEY" \
  -H "Content-Type: application/json" \
  -H "Idempotency-Key: carrinho-8842" \
  -d '{
    "receiver": "+5511999999999",
    "templateName": "arara_recovery_cart_abandoned_charge_pt_br",
    "templateVariables": ["Ana", "Tênis Runner e mais 3 itens", "R$ 449,50"],
    "charge": {
      "referenceId": "carrinho-8842",
      "items": [
        { "name": "Tênis Runner", "amountCents": 29990 },
        { "name": "Meia cano alto", "amountCents": 2490, "quantity": 2 },
        { "name": "Boné", "amountCents": 7990 }
      ],
      "shippingCents": 1990,
      "paymentLink": "https://sualoja.com.br/checkout/8842"
    }
  }'
```

Para enviar do seu número, com os seus templates, siga os passos abaixo.

## Antes de começar

Todo envio pela API é real e sai do seu número. Para o primeiro envio a sua organização precisa de:

1. **Plano assinado.** Sem assinatura a API recusa o envio com `403 ACCOUNT_NOT_ACTIVATED`. Assine em [Faturamento](https://app.ararahq.com/dashboard/faturamento). Veja os planos em [Preços](/concepts/pricing).
2. **Número conectado.** Conecte em [Números](https://app.ararahq.com/dashboard/numeros). Veja [Números](/numbers).
3. **Um template aprovado pela Meta.** Crie em [Templates](https://app.ararahq.com/dashboard/templates). Veja [Templates](/concepts/templates).
4. **Saldo na carteira.** Recarregue em [Faturamento](https://app.ararahq.com/dashboard/faturamento). Veja [Carteira](/concepts/pricing#carteira).

Criar a conta e gerar a chave de API não exige plano. Você pode conectar o número e criar o template antes de assinar.

## Passo a passo

<Steps>
  <Step title="Pegue sua chave de API">
    Crie uma chave em [Chaves de API](https://app.ararahq.com/dashboard/apikeys). O valor completo aparece uma única vez.

    Guarde em variável de ambiente:

    ```bash
    export ARARA_API_KEY=ara_live_...
    ```

    <Warning>
      Nunca coloque a chave no código, no frontend ou em repositório.
    </Warning>
  </Step>

  <Step title="Envie a mensagem">
    Troque `+5511999999999` pelo seu número de WhatsApp. Troque `pedido_confirmado` pelo nome do seu template aprovado e `templateVariables` pelos valores das variáveis dele, na ordem.

    <CodeGroup>
    ```bash cURL
    curl -X POST https://api.ararahq.com/v1/messages \
      -H "Authorization: Bearer $ARARA_API_KEY" \
      -H "Content-Type: application/json" \
      -d '{
        "receiver": "+5511999999999",
        "templateName": "pedido_confirmado",
        "templateVariables": ["João", "12345"]
      }'
    ```

    ```javascript Node.js
    // enviar.js
    // Instale: npm install @ararahq/sdk
    // Rode:    node enviar.js
    const { NodeSDK } = require('@ararahq/sdk');

    const sdk = new NodeSDK({ apiKey: process.env.ARARA_API_KEY });

    async function main() {
      const response = await sdk.messages.send({
        receiver: '+5511999999999',
        templateName: 'pedido_confirmado',
        templateVariables: ['João', '12345'],
      });

      console.log(response.id, response.status);
    }

    main().catch((err) => {
      console.error(err);
      process.exit(1);
    });
    ```

    ```python Python
    # enviar.py
    # Instale: pip install ararahq-sdk
    # Rode:    python enviar.py
    from arara_api_sdk import AraraClient
    from arara_api_sdk.models.message import SendMessageRequest

    with AraraClient() as client:  # lê ARARA_API_KEY do ambiente
        response = client.messages.send(SendMessageRequest(
            receiver="+5511999999999",
            template_name="pedido_confirmado",
            template_variables=["João", "12345"],
        ))

    print(response.id, response.status)
    ```

    ```php PHP
    <?php
    // enviar.php
    // Instale: composer require ararahq/sdk
    // Rode:    php enviar.php
    require __DIR__ . '/vendor/autoload.php';

    use Arara\Arara;
    use Arara\Config;

    $sdk = new Arara(new Config(apiKey: getenv('ARARA_API_KEY')));

    // O SDK PHP exige o prefixo "whatsapp:" no receiver.
    $response = $sdk->messages->send(
        receiver: 'whatsapp:+5511999999999',
        templateName: 'pedido_confirmado',
        variables: ['João', '12345'],
    );

    echo $response['id'] . ' ' . $response['status'] . PHP_EOL;
    ```
    </CodeGroup>
  </Step>

  <Step title="Veja a resposta">
    A API responde `202 Accepted`. A mensagem foi aceita e entrou na fila de envio.

    ```json
    {
      "id": "ara_msg_k9Bf2Xq",
      "status": "PENDING",
      "mode": "LIVE",
      "sender": "whatsapp:+5511888888888",
      "receiver": "+5511999999999",
      "body": "Olá João, seu pedido 12345 foi confirmado.",
      "cost": 0.3835,
      "reason": null
    }
    ```

    `status` começa em `PENDING` e passa por `SENT`, `DELIVERED` e `READ`, ou termina em `FAILED` com o motivo em `reason`. Na API o status vem em maiúsculas. No webhook vem em minúsculas (`sent`, `delivered`, `read`, `failed`).

    Guarde o `id`. Você usa ele no próximo passo.
  </Step>

  <Step title="Consulte o status">
    Troque `ara_msg_k9Bf2Xq` pelo `id` que você recebeu:

    ```bash
    curl https://api.ararahq.com/v1/messages/ara_msg_k9Bf2Xq \
      -H "Authorization: Bearer $ARARA_API_KEY"
    ```

    A resposta tem o mesmo formato do passo anterior, com o `status` atual.

    Em produção, não consulte em loop. Receba cada mudança de status por [webhook](/webhooks).
  </Step>
</Steps>

## Deu erro?

| Resposta | O que aconteceu | O que fazer |
|---|---|---|
| `401` | A chave não existe, foi revogada, expirou ou não começa com `ara_live_`. | Confira o valor de `ARARA_API_KEY`. |
| `403` sem `error.code` | O header `Authorization` não chegou, ou a chave não tem permissão de envio. | Confira o header `Authorization: Bearer ...` e a permissão `MESSAGES_SEND` da chave. |
| `403 ACCOUNT_NOT_ACTIVATED` | A organização ainda não tem plano assinado (`details.reason` = `FIRST_SUBSCRIPTION_REQUIRED`). | Assine um plano em [Faturamento](https://app.ararahq.com/dashboard/faturamento). |
| `403 NO_DEDICATED_NUMBER` | A organização não tem número conectado. | Conecte um número em [Números](https://app.ararahq.com/dashboard/numeros). |
| `409 CONFLICT` | Não existe template com esse nome na sua organização. | Confira o `templateName` em [Templates](https://app.ararahq.com/dashboard/templates). |
| `422 TEMPLATE_NOT_SENDABLE` | O template ainda está em análise, foi reprovado ou desativado. | Aguarde a aprovação da Meta ou corrija o template. |
| `422 TEMPLATE_VARIABLES_MISMATCH` | A quantidade de variáveis não bate com o template. | Compare `templateVariables` com `details.expected`. |
| `422 INVALID_RECIPIENT` | O telefone não é válido. | Use o formato `+5511999999999`, com código do país e DDD. |
| `402 INSUFFICIENT_FUNDS` | A carteira não tem saldo para a mensagem. | Recarregue em [Faturamento](https://app.ararahq.com/dashboard/faturamento). |

A resposta foi `202` mas a mensagem não chegou? Veja [Erros de envio](/erros-de-envio). A lista completa de recusas está em [Erros](/erros).
