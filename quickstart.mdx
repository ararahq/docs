Você vai mandar uma mensagem WhatsApp **real** para o seu próprio número. Conta nova tem 3 envios gratuitos do template de demonstração `hello_world_v2`, saindo pelo número da Arara, sem plano e sem saldo. É o jeito mais rápido de ver a API funcionando.

<Note>
  Para entender antes os conceitos (janela de 24h, templates, preços), leia [Como funciona a WhatsApp Business API](/concepts/whatsapp).
</Note>

## 1. Crie a conta e gere uma chave de API

Crie sua conta no [Dashboard](https://app.ararahq.com). Em **API Keys**, gere uma chave e dê um nome que diga onde ela será usada. Toda chave é de produção (`ara_live_...`): a Arara não tem modo de teste, todo envio é real.

A chave completa só aparece uma vez. Guarde em variável de ambiente:

```bash
export ARARA_API_KEY=ara_live_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
```

<Warning>
  Nunca commite a chave e nunca a exponha no frontend. Use variável de ambiente ou um gerenciador de segredos.
</Warning>

## 2. Mande a primeira mensagem

Troque o número pelo seu WhatsApp. O `hello_world_v2` tem uma variável, que a Arara preenche com o seu primeiro nome, então não é preciso enviar `templateVariables`.

<CodeGroup>
```bash cURL
curl -X POST https://api.ararahq.com/v1/messages \
  -H "Authorization: Bearer $ARARA_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "receiver": "whatsapp:+5511987654321",
    "templateName": "hello_world_v2"
  }'
```

```typescript Node.js
// npm install @ararahq/sdk
import { NodeSDK } from '@ararahq/sdk';

const sdk = new NodeSDK({
  apiKey: process.env.ARARA_API_KEY!,
});

const response = await sdk.messages.send({
  receiver: 'whatsapp:+5511987654321',
  templateName: 'hello_world_v2',
});

console.log(response.id, response.status);
```

```python Python
# pip install ararahq-sdk
import os
from arara_api_sdk import AraraClient
from arara_api_sdk.models.message import SendMessageRequest

with AraraClient(api_key=os.environ["ARARA_API_KEY"]) as client:
    response = client.messages.send(SendMessageRequest(
        receiver="whatsapp:+5511987654321",
        template_name="hello_world_v2",
    ))

print(response.id, response.status)
```

```php PHP
// composer require ararahq/sdk
use Arara\Arara;
use Arara\Config;

$sdk = new Arara(new Config(apiKey: getenv('ARARA_API_KEY')));

$response = $sdk->messages->send(
    receiver: 'whatsapp:+5511987654321',
    templateName: 'hello_world_v2',
);

echo "{$response['id']} {$response['status']}";
```

```java Java
// implementation("com.ararahq:arara-java-sdk:1.8.1")
import com.ararahq.arara.sdk.Arara;
import com.ararahq.arara.sdk.models.SendMessageRequest;

Arara arara = Arara.builder()
    .apiKey(System.getenv("ARARA_API_KEY"))
    .build();

var response = arara.getMessages().send(
    SendMessageRequest.builder()
        .receiver("whatsapp:+5511987654321")
        .templateName("hello_world_v2")
        .build()
);

System.out.println(response.getId() + " " + response.getStatus());
```

```go Go
// go get github.com/ararahq/arara-go-sdk
package main

import (
    "context"
    "fmt"
    "log"
    "os"

    arara "github.com/ararahq/arara-go-sdk"
)

func main() {
    client, err := arara.NewClient(os.Getenv("ARARA_API_KEY"))
    if err != nil {
        log.Fatal(err)
    }

    resp, err := client.Messages.Send(context.Background(), &arara.SendMessageRequest{
        Receiver:     "whatsapp:+5511987654321",
        TemplateName: "hello_world_v2",
    })
    if err != nil {
        log.Fatal(err)
    }

    fmt.Println(resp.ID, resp.Status)
}
```
</CodeGroup>

Resposta esperada (`202 Accepted`):

```json
{
  "id": "ara_msg_k9Bf2Xq",
  "status": "PENDING",
  "mode": "LIVE",
  "sender": "whatsapp:+551144440000",
  "receiver": "whatsapp:+5511987654321",
  "cost": 0
}
```

`status` começa em `PENDING` e evolui para `SENT`, `DELIVERED` e `READ` quando a mensagem é lida. Se falhar, vira `FAILED` com o motivo em `reason`.

## 3. Consulte o status

```bash
curl https://api.ararahq.com/v1/messages/ara_msg_k9Bf2Xq \
  -H "Authorization: Bearer $ARARA_API_KEY"
```

Em produção, prefira receber status por [webhook](/webhooks) em vez de consultar em loop.

## 4. Da demonstração para a operação

Os 3 envios de demonstração servem só para ver a entrega. Para enviar as suas mensagens:

<Steps>
  <Step title="Assine um plano">
    Essencial, Voo ou Primeira Classe. Ver [Preços](/concepts/pricing).
  </Step>
  <Step title="Conecte um número">
    Conecte o seu número de WhatsApp Business ou use um número provisionado pela Arara. Ver [Números](/numbers).
  </Step>
  <Step title="Crie seus templates">
    Mensagem fora da janela de 24h precisa de template aprovado pela Meta. Ver [Templates](/concepts/templates).
  </Step>
  <Step title="Carregue a carteira e ligue a auto-recarga">
    Mensagens são pagas com saldo pré-pago. Sem saldo, o envio é recusado.
  </Step>
  <Step title="Configure o webhook">
    Receba status (`sent`, `delivered`, `read`, `failed`) e mensagens recebidas em tempo real. Ver [Webhooks](/webhooks).
  </Step>
</Steps>

## Erros comuns

| Resposta | Causa provável | O que fazer |
|---|---|---|
| `401` | Chave inválida, revogada ou ausente | Confira `ARARA_API_KEY` (`ara_live_...`). |
| `409 CONFLICT` | Template não existe nesta organização | Confira o nome ou crie o template. |
| `422 TEMPLATE_NOT_SENDABLE` | Template ainda em análise, rejeitado ou desabilitado | Aguarde a aprovação ou corrija e reenvie. |
| `422 CONVERSATION_WINDOW_CLOSED` | Texto livre fora da janela de 24h | Use um template aprovado. Ver [Janela de 24h](/concepts/24h-window). |
| `422 UNPROCESSABLE_ENTITY` | Os 3 envios de demonstração já foram usados | Assine um plano para continuar. |
| `402 INSUFFICIENT_FUNDS` | Carteira sem saldo | Recarregue no Dashboard ou ligue a auto-recarga. |

Lista completa em [Erros](/erros).
