## Automação de workflow

n8n, Zapier e Make não têm node ou app nativo. Use os blocos genéricos:

- **Enviar**: módulo HTTP chamando `POST https://api.ararahq.com/v1/messages` com `Authorization: Bearer ara_live_...`. Guarde a chave no cofre de credenciais da ferramenta.
- **Receber eventos**: aponte o webhook da organização para a URL de trigger da ferramenta e valide `X-Arara-Signature`. Veja [Webhooks](/webhooks).
- **Eventos de recuperação**: HTTP para o endpoint de recuperação com o header `X-Arara-Event`. Veja [Recuperação de receita](/recovery).
