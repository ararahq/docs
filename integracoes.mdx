## Automação de workflow (n8n, Zapier, Make)

Não há node ou app nativo. Funciona hoje com os blocos genéricos:

- **Enviar**: módulo HTTP chamando `POST https://api.ararahq.com/v1/messages` com `Authorization: Bearer ara_live_...`.
- **Receber eventos**: aponte o webhook da organização para a URL de trigger da ferramenta e valide `X-Arara-Signature`. Veja [Webhooks](/webhooks).
- **Eventos de recuperação**: HTTP para o endpoint de recuperação com header `X-Arara-Event`. Veja [Revenue Recovery](/recovery).
