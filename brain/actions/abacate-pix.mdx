A Action `ABACATE_PIX` permite que o Brain crie uma cobrança Pix na **sua** conta AbacatePay e envie o link de pagamento e o código copia-e-cola na conversa.

<Note>
  Exige uma conta no [AbacatePay](https://abacatepay.com) com API key ativa. O dinheiro cai direto na sua conta AbacatePay.
</Note>

## Quando o Brain usa

Quando o cliente pede pra pagar, finalizar a compra ou receber o Pix **e o valor está claro**. Se o valor não estiver claro, o Brain é instruído a perguntar antes de gerar.

Parâmetros que o Brain preenche:

| Parâmetro | Obrigatório | Descrição |
|---|---|---|
| `amount_cents` | Sim | Valor em centavos (`8990` = R$ 89,90) |
| `description` | Sim | Descrição da cobrança, até 100 caracteres |
| `customer_name` | Não | Nome do cliente |

## Setup

<Steps>
  <Step title="Pegue sua API key no AbacatePay">
    No painel do AbacatePay, em configurações de API.
  </Step>
  <Step title="Habilite na Arara">
    No dashboard em **Brain**, ou via API:
    ```bash
    curl -X POST https://api.ararahq.com/v1/brain/actions \
      -H "Authorization: Bearer ara_live_xxx" \
      -H "Content-Type: application/json" \
      -d '{
        "actionType": "ABACATE_PIX",
        "enabled": true,
        "config": { "apiKey": "sua_chave_abacatepay" }
      }'
    ```
    A chave é criptografada antes de gravar e volta mascarada no `GET /v1/brain/actions`.
  </Step>
</Steps>

## Fluxo

```
Cliente:   "Quero a oferta de R$ 47"
  ↓
Brain:     [ABACATE_PIX → cria Pix de R$ 47 com validade de 1 hora]
  ↓
Brain:     "Aqui o PIX (R$ 47,00):
            <link de pagamento>

            Ou copia e cola: <código Pix>

            Expira em 1h."
```

A cobrança é criada com validade fixa de 1 hora. O valor máximo aceito é R$ 1.000.000; acima disso a Action recusa.

## Limitações

- **Sem confirmação automática de pagamento**: a Action gera a cobrança, mas a Arara não recebe o webhook de pagamento da sua conta AbacatePay. Pra confirmar no chat, trate o webhook do AbacatePay no seu sistema e responda a conversa (dentro da janela de 24h, `POST /v1/conversations/reply`).
- **Só Pix**: pra cartão, use a Action [Stripe](/brain/actions/stripe).
- **Validade fixa**: 1 hora, não configurável.
- **Sem split**: o pagamento vai inteiro pra conta AbacatePay configurada.
