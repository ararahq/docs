title: "Links rastreados em campanhas"
description: "Como a Arara encurta e rastreia automaticamente os links das suas mensagens, e como medir clique e conversão."
---

URL longa em mensagem de WhatsApp afasta clique e não diz quem clicou. A Arara troca as URLs das suas mensagens por links curtos `https://ararahq.com/l/{codigo}`, um por mensagem, e registra cada clique.

## O que é encurtado

| Onde está a URL | O que acontece |
|---|---|
| Botão `SMART_LINK` do template | Cada mensagem ganha um link curto pro destino do botão |
| Variável de template que começa com `http` | A variável é trocada pelo link curto |
| `body` de mensagem de sessão (janela de 24h) | Toda URL do texto é trocada pelo link curto |

Você não precisa encurtar nada antes de enviar.

## Opção 1: botão SMART_LINK (recomendado)

O link fica no botão, fora do texto, e o domínio exibido é sempre o mesmo.

Crie o template com o botão:

```json
{
  "name": "oferta_verao",
  "category": "MARKETING",
  "language": "pt_BR",
  "body": "Oi {{1}}, a coleção de verão chegou. Toque pra ver a sua seleção.",
  "samples": { "1": "João" },
  "buttons": [
    { "type": "SMART_LINK", "text": "Ver oferta", "url": "https://sualoja.com/verao" }
  ]
}
```

No envio, personalize o destino por mensagem com `smartLinkUrl` e, se quiser, marque o cliente com `smartLinkParam` (vira `slp={valor}` na URL de destino):

```typescript
await fetch('https://api.ararahq.com/v1/messages', {
  method: 'POST',
  headers: {
    'Authorization': `Bearer ${process.env.ARARA_API_KEY}`,
    'Content-Type': 'application/json',
  },
  body: JSON.stringify({
    receiver: 'whatsapp:+5511999999999',
    templateName: 'oferta_verao',
    templateVariables: ['João'],
    smartLinkUrl: 'https://sualoja.com/produto/camisa-azul?utm_source=whatsapp',
    smartLinkParam: 'cliente-8812',
  }),
});
```

O tipo `SendMessageRequest` do SDK Node 1.8.1 não declara `smartLinkUrl` nem `smartLinkParam`, por isso o exemplo usa `fetch`.

## Opção 2: URL como variável

Se o template tem a URL no corpo (`Confira: {{2}} e aproveite.`), passe a URL completa na variável:

```typescript
import { NodeSDK } from '@ararahq/sdk';

const sdk = new NodeSDK({ apiKey: process.env.ARARA_API_KEY! });

await sdk.messages.send({
  receiver: 'whatsapp:+5511999999999',
  templateName: 'oferta_verao_texto',
  templateVariables: ['João', 'https://sualoja.com/produto/camisa-azul?ref=ads'],
});
```

O cliente recebe `https://ararahq.com/l/{codigo}` no lugar da URL.

## Em campanhas

`POST /v1/campaigns` e `POST /v1/messages/batch` aplicam o mesmo encurtamento a cada contato. Numa campanha com A/B test, os cliques nesses links alimentam a métrica `CLICKED`. Ver [Marketing no WhatsApp](/marketing).

## Acompanhando cliques e conversões

- **Cliques**: o dashboard, em **Links**, mostra os links de campanha e avulsos com a contagem de cliques. Cada clique registra IP, user agent, referer e país (quando disponível).
- **Conversões**: reporte a venda do seu backend com o telefone do cliente pra ligá-la à mensagem. Ver [Atribuição de conversão](/smart-links/attribution).

A Arara não envia webhook por clique.
