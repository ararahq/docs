Pra enviar código de verificação (login, 2FA, confirmação de telefone), use um template da categoria **AUTHENTICATION**. O WhatsApp mostra o código com um botão **Copiar código**, e a Meta aplica regras próprias pra essa categoria.

## 1. Criar o template

O template de autenticação tem forma fixa. Ao criar com `category: "AUTHENTICATION"`, a Arara monta o corpo padrão **"`{{1}}` é o seu código de verificação"** e o botão **Copiar código**. Você só escolhe o nome.

```bash
curl -X POST https://api.ararahq.com/v1/templates \
  -H "Authorization: Bearer ara_live_xxx" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "codigo_verificacao",
    "category": "AUTHENTICATION",
    "language": "pt_BR",
    "body": "{{1}} é o seu código de verificação"
  }'
```

- `body` continua obrigatório na requisição, mas o texto enviado pra aprovação é o padrão.
- Não envie `buttons`: o botão de copiar é gerado automaticamente.
- Acompanhe a aprovação com `GET /v1/templates/{id}/status` (o `id` é o UUID devolvido na criação) ou pelo webhook `template.updated`.

Também dá pra criar no dashboard, escolhendo a categoria **AUTHENTICATION**.

## 2. Enviar o código

Passe o código como única variável. Ele preenche o corpo e o botão de copiar.

```javascript
import { randomUUID } from 'node:crypto';

async function sendOtp(phone, code) {
  const response = await fetch('https://api.ararahq.com/v1/messages', {
    method: 'POST',
    headers: {
      'Authorization': `Bearer ${process.env.ARARA_API_KEY}`,
      'Content-Type': 'application/json',
      'Idempotency-Key': randomUUID(),
    },
    body: JSON.stringify({
      receiver: `whatsapp:${phone}`,
      templateName: 'codigo_verificacao',
      templateVariables: [code],
    }),
  });

  if (!response.ok) {
    const { error } = await response.json();
    throw new Error(`Falha ao enviar OTP: ${error?.code}`);
  }

  return response.json(); // { id: "ara_msg_...", status: "PENDING", ... }
}
```

Com o SDK Node (`@ararahq/sdk` 1.8.1):

```typescript
import { NodeSDK } from '@ararahq/sdk';

const sdk = new NodeSDK({ apiKey: process.env.ARARA_API_KEY! });

await sdk.messages.send({
  receiver: 'whatsapp:+5511999999999',
  templateName: 'codigo_verificacao',
  templateVariables: ['482931'],
});
```

A API responde `202`. A confirmação de entrega chega pelo webhook `message.status_updated` (`sent`, `delivered`, `read` ou `failed`).

## Boas práticas

- **Gere e valide o código no seu backend.** A Arara só entrega a mensagem. Guarde o hash do código com o horário de criação e aplique a validade no seu sistema (5 a 10 minutos é o comum).
- **Limite tentativas por número e por IP no seu backend.** Reenvio sem limite vira custo e abuso.
- **Não registre o código em log** nem o coloque em URL.
- **Trate falha de entrega.** Se chegar `message.status_updated` com `failed`, ofereça outro canal (SMS, email). Ver [Erros de envio](/erros).
