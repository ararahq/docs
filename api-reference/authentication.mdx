Toda integração autentica com **API key** no header `Authorization`:

```
Authorization: Bearer ara_live_...
```

O painel usa sessão de usuário, criada no login. Essa sessão não serve para integração, e as rotas exclusivas do painel não aceitam API key.

## Formato da chave

```
ara_live_<43 caracteres>
```

Toda chave é **LIVE**: a mensagem é entregue de verdade e o custo sai da carteira. Não existe chave de teste. Um token que começa com `ara_` mas não com `ara_live_` é recusado com `401`.

## Onde criar

A chave é criada, listada, rotacionada e revogada no painel, na tela de API Keys. O valor completo aparece **uma única vez**, na criação. Depois disso a Arara só mostra os 4 últimos caracteres.

<Warning>
  As rotas `/v1/api-keys` existem, mas recusam chamada autenticada por API key (`403 RESOURCE_FORBIDDEN`): uma chave não gerencia chaves. Veja [API Keys](/api-reference/endpoint/v2/api-keys).
</Warning>

## Permissões

Chave criada sem escolher permissões tem acesso total (`ADMIN`). Ao restringir, cada permissão libera um conjunto de rotas:

| Permissão | Libera |
|---|---|
| `READ` | `GET` em `/v1/messages`, `/v1/campaigns`, `/v1/templates` e `/v1/organizations/me/numbers` |
| `MESSAGES_SEND` | Escrita (qualquer método exceto `GET`) em `/v1/messages/**` e `POST /v1/media/upload` |
| `TEMPLATES_WRITE` | Escrita em `/v1/templates/**` |
| `CAMPAIGNS_SEND` | Escrita em `/v1/campaigns/**` (inclui estimativa por telefones, cancelamento e A/B) |
| `CONTACTS_WRITE` | Escrita em `/v1/contacts/**` (inclui a remoção LGPD) |
| `WEBHOOKS_MANAGE` | `POST /webhook/cart` (rota legada) |
| `ADMIN` | Tudo que aceita API key |

Todo o resto exige `ADMIN`, inclusive leituras que não estão na linha `READ`: `GET /v1/contacts`, `/v1/conversations`, `/v1/opt-outs`, `/v1/smart-links/whatsapp`, `/dashboard/*`, `/v1/pricing/current`, `/auth/me`.

Chaves antigas com `scope` continuam valendo: `READ` equivale a `READ`; `SEND` equivale a `READ` + `MESSAGES_SEND` + `CAMPAIGNS_SEND`; `ADMIN` equivale a `ADMIN`.

<Note>
  Uma chave de acesso total também altera recarga automática, perfil comercial e endpoint de recuperação. Para servidores que só enviam, crie uma chave com `MESSAGES_SEND` (e `READ` se precisar consultar status).
</Note>

## Restrições opcionais

Configuradas no painel, por chave:

| Restrição | Efeito |
|---|---|
| Expiração (`expiresAt`) | Depois da data, a chave responde `401`. |
| IP allowlist | Lista CSV de IPs e faixas CIDR IPv4 (`203.0.113.5,10.0.0.0/8`). Chamada de outro IP responde `401`. Exige plano com trilha de auditoria; sem ele, `403 PLAN_FEATURE_LOCKED`. |
| Limite diário de envio | Teto de mensagens por dia (UTC), de 1 a 1.000.000. Estourou: `429 SEND_RATE_LIMITED`. Campanha consome o número de contatos de uma vez. |

## Rotação e revogação

- **Rotacionar** cria uma chave nova com as mesmas permissões e restrições e **revoga a anterior na hora**. Não há período de convivência: troque a variável de ambiente antes de rotacionar, ou crie uma segunda chave, migre e revogue a antiga.
- **Revogar** invalida a chave imediatamente. A próxima chamada responde `401`.

## Erros de autenticação

Falhas no filtro de autenticação saem no formato padrão do Spring, **sem** `error.code`:

```json
{
  "timestamp": "2026-09-15T14:30:00.000+00:00",
  "status": 401,
  "error": "Unauthorized",
  "path": "/v1/messages"
}
```

| HTTP | Causa |
|---|---|
| `401` | Chave inexistente, com formato errado, revogada, expirada ou IP fora da allowlist. |
| `403` | Header `Authorization` ausente, rota que não aceita API key, ou chave válida sem permissão para a rota. |
| `403` com `error.code` | Regra de negócio da rota (plano, conta, recurso de outra organização). Ver [Erros](/erros). |

Ramifique pelo status: `401` pede outra chave; `403` sem `error.code` pede outra permissão.

## Boas práticas

- Guarde a chave em variável de ambiente ou cofre de segredos, nunca no código.
- Nunca exponha a chave no frontend nem em URL.
- Uma chave por serviço, com a menor permissão que resolve.
- Rotacione periodicamente e revogue quando alguém com acesso sair do time.
