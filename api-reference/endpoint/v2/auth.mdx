---
title: 'Identidade da chave'
description: 'Descubra a qual usuário e a quais organizações uma API key pertence. Útil para validar a chave no boot da integração.'
---

Dois endpoints de leitura que respondem com a identidade do usuário dono da chave. Servem para conferir se a chave configurada é a esperada antes de começar a enviar.

**Base URL:** `https://api.ararahq.com`

<Note>
  O login do painel (email, link mágico, OAuth e WhatsApp) é interno e não faz parte da API pública. A antiga troca de token Firebase (`POST /auth`) não existe mais. Integrações usam só [API key](/api-reference/authentication).
</Note>

Os dois endpoints exigem chave com permissão `ADMIN`.

---

## Usuário da chave

`GET /auth/me`

```bash
curl https://api.ararahq.com/auth/me \
  -H "Authorization: Bearer ara_live_xxx"
```

Resposta (`200 OK`):

```json
{
  "name": "Maria Silva",
  "email": "maria@exemplo.com.br",
  "role": null,
  "emailPending": false
}
```

| Campo | Tipo | Descrição |
|-------|------|-----------|
| `name` | string | Nome do usuário. |
| `email` | string | Email do usuário. |
| `role` | string \| null | Hoje sempre `null` nesta rota. |
| `emailPending` | boolean | Hoje sempre `false` nesta rota. |

## Organizações do usuário

`GET /auth/me/organizations`

```bash
curl https://api.ararahq.com/auth/me/organizations \
  -H "Authorization: Bearer ara_live_xxx"
```

Resposta (`200 OK`):

```json
{
  "data": [
    {
      "id": "7f8a1c2d-4e5f-6789-abcd-ef0123456789",
      "slug": "minha-empresa",
      "name": "Minha Empresa",
      "role": "OWNER",
      "mode": "live"
    }
  ]
}
```

| Campo | Tipo | Descrição |
|-------|------|-----------|
| `id` | UUID | Organização. |
| `slug` | string \| null | Identificador legível. |
| `name` | string | Nome exibido. |
| `role` | string | Papel do usuário naquela organização. |
| `mode` | string | `live` quando a conta do usuário está ativa; `test` enquanto não está. |

A lista vem em ordem de entrada do usuário nas organizações. A API key sempre age sobre a **organização principal** do usuário dono da chave.

## Erros

| HTTP | Quando |
|------|--------|
| `401` | Chave inválida, revogada ou expirada (formato padrão do Spring, sem `error.code`). |
| `403` | Header ausente ou chave sem permissão `ADMIN`. |
