Brain Actions são integrações que o [Brain](/brain) pode invocar durante uma conversa do WhatsApp. O cliente pede pra pagar, o Brain gera o Pix no AbacatePay e manda o link. Pede um horário, o Brain consulta o Cal.com e confirma.

<Note>
  Actions só rodam com o Brain ligado. Configurar uma Action (`POST /v1/brain/actions`) responde `403 PLAN_FEATURE_LOCKED` se o plano não inclui Brain e `403 NO_DEDICATED_NUMBER` se a organização não tem número dedicado.
</Note>

## Ações disponíveis

| `actionType` | O que faz | Config |
|---|---|---|
| `ABACATE_PIX` | Gera cobrança Pix no AbacatePay e envia link e copia-e-cola | `apiKey` |
| `CAL_COM_BOOKING` | Lista horários livres e cria agendamento no Cal.com | `apiKey`, `eventTypeId` |
| `STRIPE_CHECKOUT` | Cria um Payment Link na sua conta Stripe | `secretKey` (ou `apiKey`) |
| `META_CATALOG_SEND` | Envia o card de um produto do catálogo Meta na conversa | `catalogId`, `phoneNumberId` |
| `HANDOFF_TO_HUMAN` | Encaminha a conversa pra um atendente | nenhuma (habilitada por padrão) |

## Como funciona

<Steps>
  <Step title="Você habilita a Action">
    No dashboard em **Brain**, ou via `POST /v1/brain/actions`.
  </Step>
  <Step title="O Brain decide quando chamar">
    Cada Action descreve pro modelo o que faz, quando usar e quais parâmetros precisa. Só Actions habilitadas entram no prompt.
  </Step>
  <Step title="A Arara executa">
    A chamada ao provedor roda no backend da Arara com as credenciais da sua organização. Toda execução fica registrada.
  </Step>
  <Step title="O Brain responde no WhatsApp">
    Com o link, o horário ou a confirmação que a Action devolveu.
  </Step>
</Steps>

## Configurando via API

```bash
curl -X POST https://api.ararahq.com/v1/brain/actions \
  -H "Authorization: Bearer ara_live_xxx" \
  -H "Content-Type: application/json" \
  -d '{
    "actionType": "ABACATE_PIX",
    "enabled": true,
    "config": {
      "apiKey": "sua_chave_abacatepay"
    }
  }'
```

Responde `204`. O mesmo endpoint cria ou atualiza (uma linha por `actionType`).

- Pra ligar ou desligar sem reenviar a chave, mande `enabled` com `config` vazio: a config salva é preservada.
- Valores sensíveis são criptografados antes de gravar.

Listar o estado de todas as Actions:

```bash
curl https://api.ararahq.com/v1/brain/actions \
  -H "Authorization: Bearer ara_live_xxx"
```

Cada item traz `type`, `displayName`, `description`, `parameters`, `enabled`, `configured`, `config` (com segredos mascarados) e `invocations30d`.
