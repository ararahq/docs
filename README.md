# Documentação da Arara

Site da documentação da API de WhatsApp da AraraHQ, em [docs.ararahq.com](https://docs.ararahq.com). As páginas são MDX no formato Mintlify. A navegação fica em `docs.json`.

## Preview local

Na raiz deste repositório:

```bash
npm i -g mint
mint dev
```

O preview sobe em `http://localhost:3000`.

## Publicação

O deploy usa o app da Mintlify ligado a este repositório. Push na branch padrão publica o site.
