## Criando um Novo SDK

Se você quer criar um SDK para uma linguagem que ainda não tem suporte, siga este guia para garantir consistência e qualidade.

### Regras e Diretrizes

Antes de começar, certifique-se de seguir estas regras:

#### 1. Estrutura do Repositório

- **Nome**: Use o padrão `arara-{linguagem}-sdk` (ex: `arara-python-sdk`, `arara-java-sdk`)
- **Organização**: Crie o repositório na sua conta do GitHub. Para ele entrar na organização `ararahq`, fale com [suporte@ararahq.com](mailto:suporte@ararahq.com)
- **Licença**: Use a licença MIT
- **README**: Deve incluir:
  - Instalação
  - Exemplo básico de uso
  - Link para documentação completa
  - Badges (build status, version, license)

#### 2. Funcionalidades Mínimas

Todo SDK deve implementar pelo menos:

- **Autenticação**: API Key no header `Authorization: Bearer ara_live_...`. Chave inválida ou ausente responde **403** (não 401)
- **Mensagens**: `POST /v1/messages` (resposta `202`) e `GET /v1/messages/{internalId}`
- **Idempotência**: aceitar uma chave opcional e enviá-la no header `Idempotency-Key` do envio
- **Tratamento de erros**: ler o envelope `{ "error": { "code", "message", "details" } }` e expor status HTTP e `code`. Em `429`, expor o header `Retry-After`
- **Validação**: validação básica de parâmetros antes de enviar
- **Type safety**: tipos fortes quando a linguagem suporta (TypeScript, Java, etc.)

O contrato de `POST /v1/messages`:

| Campo | Tipo | Observação |
|---|---|---|
| `receiver` | string | Obrigatório. E.164, aceita prefixo `whatsapp:` (ex: `whatsapp:+5511999999999`) |
| `templateName` | string | Nome do template aprovado |
| `templateVariables` | string[] | Posições `{{1}}`, `{{2}}`... Se o template tem header de mídia, a URL da mídia vai como primeiro elemento. `variables` é aceito como alias |
| `body` | string | Texto livre, só dentro da janela de 24h |
| `scheduled_at` | string ISO 8601 | Agendamento (alias `scheduledAt`) |

A resposta traz `id` (`ara_msg_...`), `status` em maiúsculas (`PENDING`, `SCHEDULED`, `PROCESSING`, `SENT`, `DELIVERED`, `READ`, `FAILED`, `CANCELED`), `sender`, `receiver`, `body`, `cost` e `reason`.

#### 3. Padrões de Código

- **Nomenclatura**: Siga as convenções da linguagem
- **Documentação**: Documente todas as funções públicas
- **Testes**: Inclua testes unitários e de integração
- **Exemplos**: Forneça exemplos práticos no README e na documentação

#### 4. Gerenciamento de Versões

- Use [Semantic Versioning](https://semver.org/) (MAJOR.MINOR.PATCH)
- Mantenha um CHANGELOG.md atualizado
- Tag releases no GitHub

  <Step title="3. Implementação do Cliente Base">
    Crie a classe/função principal do cliente:

    - **Inicialização**: Recebe a API Key
    - **Configuração HTTP**: Base URL, headers padrão, timeout explícito
    - **Tratamento de Erros**: Converte respostas não-2xx em exceção com o envelope de erro
    - **Método genérico de requisição**: Para fazer chamadas HTTP, aceitando headers extras (ex: `Idempotency-Key`)

    <CodeGroup>
    ```typescript TypeScript
    const DEFAULT_TIMEOUT_MS = 10_000;

    export class AraraClient {
      private readonly baseURL = 'https://api.ararahq.com';

      constructor(private readonly apiKey: string) {
        if (!apiKey) {
          throw new Error('API Key is required');
        }
      }

      async request<T>(
        method: string,
        path: string,
        body?: unknown,
        extraHeaders?: Record<string, string>,
      ): Promise<T> {
        const response = await fetch(`${this.baseURL}${path}`, {
          method,
          headers: {
            Authorization: `Bearer ${this.apiKey}`,
            'Content-Type': 'application/json',
            ...extraHeaders,
          },
          body: body ? JSON.stringify(body) : undefined,
          signal: AbortSignal.timeout(DEFAULT_TIMEOUT_MS),
        });

        if (!response.ok) {
          throw await AraraError.fromResponse(response);
        }

        return response.json() as Promise<T>;
      }
    }
    ```

    ```python Python
    from typing import Any, Dict, Optional

    import requests

    DEFAULT_TIMEOUT_SECONDS = 10

    class AraraClient:
        def __init__(self, api_key: str):
            if not api_key:
                raise ValueError("API Key is required")
            self.api_key = api_key
            self.base_url = "https://api.ararahq.com"

        def _request(
            self,
            method: str,
            path: str,
            data: Optional[Dict[str, Any]] = None,
            extra_headers: Optional[Dict[str, str]] = None,
        ) -> Dict[str, Any]:
            headers = {
                "Authorization": f"Bearer {self.api_key}",
                "Content-Type": "application/json",
                **(extra_headers or {}),
            }

            response = requests.request(
                method=method,
                url=f"{self.base_url}{path}",
                headers=headers,
                json=data,
                timeout=DEFAULT_TIMEOUT_SECONDS,
            )

            if not response.ok:
                retry_after = response.headers.get("Retry-After")
                payload = response.json() if response.content else {}
                raise AraraError(
                    response.status_code,
                    payload,
                    int(retry_after) if retry_after and retry_after.isdigit() else None,
                )

            return response.json()
    ```

    ```java Java
    public class AraraClient {
        private static final Duration TIMEOUT = Duration.ofSeconds(10);
        private final String apiKey;
        private final String baseURL = "https://api.ararahq.com";
        private final HttpClient httpClient;

        public AraraClient(String apiKey) {
            if (apiKey == null || apiKey.isEmpty()) {
                throw new IllegalArgumentException("API Key is required");
            }
            this.apiKey = apiKey;
            this.httpClient = HttpClient.newBuilder()
                .connectTimeout(TIMEOUT)
                .build();
        }

        HttpResponse<String> request(
            String method,
            String path,
            String body,
            String idempotencyKey
        ) throws IOException, InterruptedException, AraraException {
            HttpRequest.Builder builder = HttpRequest.newBuilder()
                .uri(URI.create(baseURL + path))
                .timeout(TIMEOUT)
                .header("Authorization", "Bearer " + apiKey)
                .header("Content-Type", "application/json")
                .method(method, body != null
                    ? HttpRequest.BodyPublishers.ofString(body)
                    : HttpRequest.BodyPublishers.noBody());

            if (idempotencyKey != null) {
                builder.header("Idempotency-Key", idempotencyKey);
            }

            HttpResponse<String> response = httpClient.send(
                builder.build(),
                HttpResponse.BodyHandlers.ofString()
            );

            if (response.statusCode() >= 400) {
                JsonNode error = new ObjectMapper().readTree(response.body()).path("error");
                throw new AraraException(
                    response.statusCode(),
                    error.path("code").asText(null),
                    error.path("message").asText(null),
                    response.body()
                );
            }

            return response;
        }
    }
    ```

  <Step title="4. Implementação do Recurso de Mensagens">
    Crie a classe/função para enviar mensagens:

    - **Método `send`**: Recebe `receiver`, `templateName`, `templateVariables` e uma chave de idempotência opcional
    - **Validação**: Valida formato do número e parâmetros obrigatórios
    - **Retorno tipado**: Retorna um objeto com os campos da resposta da API

    <CodeGroup>
    ```typescript TypeScript
    export interface SendMessageParams {
      receiver: string;
      templateName: string;
      templateVariables?: string[];
    }

    export interface Message {
      id: string;
      status: string;
      mode: string;
      sender: string;
      receiver: string;
      body: string | null;
      cost: number | null;
      reason: string | null;
    }

    const E164 = /^(whatsapp:)?\+[1-9]\d{6,14}$/;

    export class Messages {
      constructor(private client: AraraClient) {}

      async send(params: SendMessageParams, idempotencyKey?: string): Promise<Message> {
        if (!E164.test(params.receiver)) {
          throw new Error('Receiver must be E.164, e.g. whatsapp:+5511999999999');
        }

        return this.client.request(
          'POST',
          '/v1/messages',
          {
            receiver: params.receiver,
            templateName: params.templateName,
            templateVariables: params.templateVariables ?? [],
          },
          idempotencyKey ? { 'Idempotency-Key': idempotencyKey } : undefined,
        );
      }
    }
    ```

    ```python Python
    import re
    from dataclasses import dataclass
    from typing import List, Optional

    E164 = re.compile(r"^(whatsapp:)?\+[1-9]\d{6,14}$")

    @dataclass
    class SendMessageParams:
        receiver: str
        template_name: str
        template_variables: Optional[List[str]] = None

    @dataclass
    class Message:
        id: str
        status: str
        mode: str
        sender: str
        receiver: str
        body: Optional[str]
        cost: Optional[float]
        reason: Optional[str]

    class Messages:
        def __init__(self, client: AraraClient):
            self.client = client

        def send(self, params: SendMessageParams, idempotency_key: Optional[str] = None) -> Message:
            if not E164.match(params.receiver):
                raise ValueError("Receiver must be E.164, e.g. whatsapp:+5511999999999")

            data = {
                "receiver": params.receiver,
                "templateName": params.template_name,
                "templateVariables": params.template_variables or [],
            }
            headers = {"Idempotency-Key": idempotency_key} if idempotency_key else None

            response = self.client._request("POST", "/v1/messages", data, headers)
            return Message(**{k: response.get(k) for k in Message.__dataclass_fields__})
    ```

    ```java Java
    public record SendMessageParams(
        String receiver,
        String templateName,
        List<String> templateVariables
    ) {}

    public record Message(
        String id,
        String status,
        String mode,
        String sender,
        String receiver,
        String body,
        BigDecimal cost,
        String reason
    ) {}

    public class Messages {
        private static final Pattern E164 = Pattern.compile("^(whatsapp:)?\\+[1-9]\\d{6,14}$");
        private final AraraClient client;
        private final ObjectMapper mapper = new ObjectMapper();

        public Messages(AraraClient client) {
            this.client = client;
        }

        public Message send(SendMessageParams params, String idempotencyKey)
                throws IOException, InterruptedException, AraraException {
            if (!E164.matcher(params.receiver()).matches()) {
                throw new IllegalArgumentException(
                    "Receiver must be E.164, e.g. whatsapp:+5511999999999"
                );
            }

            Map<String, Object> body = Map.of(
                "receiver", params.receiver(),
                "templateName", params.templateName(),
                "templateVariables", params.templateVariables() != null
                    ? params.templateVariables() : List.of()
            );

            HttpResponse<String> response = client.request(
                "POST", "/v1/messages", mapper.writeValueAsString(body), idempotencyKey
            );

            return mapper.readValue(response.body(), Message.class);
        }
    }
    ```

  <Step title="5. Tratamento de Erros">
    Implemente classes de erro específicas:

    - **AraraError/AraraException**: classe base com `statusCode`, `code`, `message` e `details`, lidos do envelope `{ "error": { ... } }`
    - **Autenticação**: a API responde **403** para chave inválida ou ausente
    - **Rate limit**: em `429`, guarde o valor de `Retry-After`
    - **Mensagens claras**: erros devem ter mensagens descritivas

    <CodeGroup>
    ```typescript TypeScript
    export class AraraError extends Error {
      constructor(
        public statusCode: number,
        public code: string | undefined,
        message: string,
        public details?: unknown,
        public retryAfter?: number,
      ) {
        super(message || `HTTP ${statusCode}`);
        this.name = 'AraraError';
      }

      static async fromResponse(response: Response): Promise<AraraError> {
        const payload = await response.json().catch(() => ({}));
        const error = payload?.error ?? {};
        const retryAfter = Number(response.headers.get('Retry-After')) || undefined;
        return new AraraError(response.status, error.code, error.message, error.details, retryAfter);
      }
    }
    ```

    ```python Python
    class AraraError(Exception):
        def __init__(self, status_code: int, payload: dict, retry_after: Optional[int] = None):
            error = payload.get("error") or {}
            self.status_code = status_code
            self.code = error.get("code")
            self.details = error.get("details")
            self.retry_after = retry_after
            super().__init__(error.get("message") or f"HTTP {status_code}")
    ```

    ```java Java
    public class AraraException extends Exception {
        private final int statusCode;
        private final String code;
        private final String responseBody;

        public AraraException(int statusCode, String code, String message, String responseBody) {
            super(message != null ? message : "HTTP " + statusCode);
            this.statusCode = statusCode;
            this.code = code;
            this.responseBody = responseBody;
        }
    }
    ```

  <Step title="6. Testes">
    Crie testes abrangentes:

    - **Testes unitários**: Para cada método, com o HTTP mockado
    - **Testes de contrato**: Payloads e respostas reais da API gravados como fixtures
    - **Testes de erro**: 400, 403, 404, 409, 429 e 5xx
    - **Cobertura**: Almeje pelo menos 80% de cobertura

    <Tip>
      A API não tem modo de teste: toda chamada com uma chave `ara_live_` é real e pode gerar custo. Rode integração só manualmente, enviando para o seu próprio número. Nunca commite API Keys.
    </Tip>
  </Step>

  <Step title="7. Documentação e Exemplos">
    Documente tudo:

    - **README completo**: Com instalação, uso básico e exemplos
    - **Documentação de API**: Use ferramentas como JSDoc, Sphinx, JavaDoc
    - **Exemplos práticos**: Casos de uso comuns
    - **CHANGELOG**: Mantenha um changelog atualizado

    Exemplo de README mínimo deve incluir:

    - Título e descrição do SDK
    - Seção de instalação com comandos específicos
    - Exemplo básico de uso
    - Link para documentação completa
    - Instruções de contribuição

    Estrutura sugerida:

  </Step>

  <Step title="8. Publicação e Manutenção">
    Publique e mantenha:

    1. **Publique no gerenciador de pacotes** da linguagem (npm, PyPI, Packagist, Maven, RubyGems etc.).

    2. **Configure CI/CD**:
       - Testes automáticos
       - Publicação automática de releases

    3. **Mantenha atualizado**:
       - Monitore mudanças na API
       - Atualize quando necessário
       - Responda a issues e PRs

    <Warning>
      Antes de publicar, certifique-se de que o SDK está completo, testado e documentado. Primeiras impressões são importantes!
    </Warning>

## Contribuindo com SDKs Existentes

Se você quer contribuir com um SDK existente:

1. **Fork o repositório** do SDK
2. **Crie uma branch** para sua feature/correção
3. **Siga as diretrizes** de contribuição do repositório
4. **Escreva testes** para suas mudanças
5. **Abra um Pull Request** com descrição clara

<Info>
  Contribuições são sempre bem-vindas! Mesmo pequenas melhorias como correções de documentação, exemplos adicionais ou melhorias de performance são valiosas.
</Info>
