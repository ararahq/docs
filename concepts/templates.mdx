Template é a mensagem **pré-aprovada pela Meta** que a empresa pode enviar a qualquer momento, inclusive para quem não escreveu nas últimas 24h. Fora da [janela de 24h](/concepts/24h-window), é a única forma de iniciar ou retomar a conversa.

Você também vai ver o nome **HSM** (Highly Structured Message) em documentação mais antiga. É a mesma coisa.

<Note>
  Regras detalhadas do que pode e não pode no conteúdo estão em [Política de templates](/templates/policy).
</Note>

## Por que template existe

A Meta limita a comunicação iniciada pela empresa para conter spam. Antes de enviar, você **declara** o conteúdo, escolhe a **categoria** e passa pela **revisão** da Meta. Aprovado, o template pode ser enviado quantas vezes precisar, respeitando opt-out e os [limites do plano](/business-rules/planos-e-limites).

## As 3 categorias

<CardGroup cols={3}>
  <Card title="UTILITY" icon="bell">
    Algo que o cliente **espera** receber: pedido confirmado, cobrança, lembrete de consulta, status de entrega.
  </Card>
  <Card title="MARKETING" icon="megaphone">
    Promoção, oferta, lançamento, reativação da base, carrinho abandonado. Exige consentimento para marketing.
  </Card>
  <Card title="AUTHENTICATION" icon="key">
    Apenas código de verificação (OTP, 2FA), com botão de copiar código.
  </Card>
</CardGroup>

Cada categoria tem uma tarifa Meta diferente, e MARKETING é a mais cara. Valores em [Preços](/concepts/pricing).

<Warning>
  A Meta pode reclassificar um template (por exemplo, de UTILITY para MARKETING) quando o conteúdo não corresponde à categoria. A partir daí ele passa a custar como a nova categoria. A Arara avisa a mudança pelo webhook `template.category_changed`.
</Warning>

## Anatomia

```
┌──────────────────────────────────────┐
│ [HEADER]                             │  Opcional: texto ou mídia (imagem, vídeo, documento)
├──────────────────────────────────────┤
│ [BODY]                               │  Obrigatório
│ Oi {{1}}, seu pedido {{2}}           │  Variáveis {{1}}, {{2}}...
│ foi confirmado! Total: R$ {{3}}.     │
├──────────────────────────────────────┤
│ [FOOTER]                             │  Opcional
│ Acompanhe pelo nosso site            │
├──────────────────────────────────────┤
│ [BUTTONS]                            │  Opcional
│ [Ver pedido] [Falar com atendente]   │
└──────────────────────────────────────┘
```

Também é possível criar **carrossel**: de 2 a 10 cards, cada um com mídia, texto e até 2 botões, todos com os mesmos tipos de botão.

## Variáveis

Cada `{{n}}` é substituído no envio, na ordem do array `templateVariables`:

```typescript
await sdk.messages.send({
  receiver: 'whatsapp:+5511999999999',
  templateName: 'pedido_confirmado',
  templateVariables: [
    'João',     // {{1}}
    'ARA-123',  // {{2}}
    '147,90',   // {{3}}
  ],
});
```

Regras validadas na criação:

- O corpo não pode começar nem terminar com uma variável. Coloque texto antes e depois.
- Cada variável precisa de um exemplo (`samples`), que a Meta usa na revisão.
- Variável usada na URL de um botão não pode ter exemplo com espaço.

No envio, a quantidade de variáveis precisa bater com o template. Se não bater, a API responde `422 TEMPLATE_VARIABLES_MISMATCH`.

## Mídia no header

Com header de mídia, a URL do arquivo vai como **primeiro elemento** de `templateVariables`, antes das variáveis do corpo:

```typescript
templateVariables: [
  'https://meusite.com/imagem.jpg', // header (mídia)
  'João',                            // {{1}} do corpo
  'ARA-123',                         // {{2}} do corpo
]
```

O campo `mediaUrl` no envio está descontinuado. Use a primeira posição de `templateVariables`.

## Botões

| Tipo | Comportamento |
|---|---|
| `QUICK_REPLY` | Resposta rápida. O clique chega como mensagem recebida no webhook. |
| `URL` | Abre um link. Aceita variável, ex.: `https://meusite.com/pedido/{{1}}`. |
| `SMART_LINK` | Link curto com rastreamento de clique da Arara. Ver [Smart Links](/smart-links). |
| `PHONE_NUMBER` | Liga para um número. |
| `COPY_CODE` | Copia um código. Usado em AUTHENTICATION. |

Limites aplicados na criação: no máximo 2 botões de link (`URL` ou `SMART_LINK`), 1 de telefone, texto do botão com até 20 caracteres.

## Criando pela API

```bash
curl -X POST https://api.ararahq.com/v1/templates \
  -H "Authorization: Bearer ara_live_xxx" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "pedido_confirmado",
    "category": "UTILITY",
    "language": "pt_BR",
    "body": "Oi {{1}}, seu pedido {{2}} foi confirmado! Total: R$ {{3}}.",
    "footer": "Acompanhe pelo nosso site",
    "samples": { "1": "João", "2": "ARA-123", "3": "147,90" },
    "buttons": [
      { "type": "URL", "text": "Ver pedido", "url": "https://meusite.com/pedido/{{2}}" }
    ]
  }'
```

| Campo | Descrição |
|---|---|
| `name` | Identificador em `snake_case`. É o nome usado no envio. |
| `category` | `MARKETING`, `UTILITY` ou `AUTHENTICATION`. |
| `language` | Padrão `pt_BR`. |
| `body` | Texto com variáveis `{{n}}`. |
| `header` / `headerType` | Texto ou URL de mídia; `headerType`: `text`, `media` ou `document`. |
| `footer` | Rodapé opcional. |
| `buttons` | Lista de botões (ver acima). |
| `samples` | Objeto com um exemplo por variável: `{ "1": "João" }`. |
| `carouselCards` | Cards do carrossel (`mediaUrl`, `body`, `buttons`). |

Resposta `201 Created` com o template e o status atual no provedor (`providerStatus`). Também dá para criar pelo [Dashboard](https://app.ararahq.com) ou pelo [MCP](/mcp-server) (`create_template`).

### Biblioteca da Meta

A Meta mantém uma biblioteca de templates UTILITY pré-aprovados. Criado a partir dela, o template já nasce aprovado, sem esperar revisão. Disponível para contas com número conectado ativo.

```bash
# Listar modelos da biblioteca
curl "https://api.ararahq.com/v1/templates/library?languageCode=pt_BR" \
  -H "Authorization: Bearer ara_live_xxx"

# Criar a partir de um modelo
curl -X POST https://api.ararahq.com/v1/templates/library \
  -H "Authorization: Bearer ara_live_xxx" \
  -H "Content-Type: application/json" \
  -d '{ "name": "confirmacao_pedido", "libraryTemplateName": "<nome_do_modelo>", "languageCode": "pt_BR" }'
```

## Ciclo de aprovação

```
[Você submete]
     ↓
[Arara valida estrutura, variáveis e exemplos antes de enviar]
     ↓
[Meta revisa]
     ↓
[Webhook template.updated com o novo status]
     ↓
APPROVED                      REJECTED
     ↓                           ↓
Pode enviar                   Veja o motivo, corrija e submeta de novo
```

| Status | Pode enviar? | Resposta da API no envio |
|---|---|---|
| `APPROVED` | Sim | |
| `PENDING` | Não | `422 TEMPLATE_NOT_SENDABLE` |
| `REJECTED` | Não | `422 TEMPLATE_NOT_SENDABLE` |
| `DISABLED` | Não | `422 TEMPLATE_NOT_SENDABLE` |
| `PAUSED` | Não | `422 TEMPLATE_PAUSED` |

Consulte o status com `GET /v1/templates/{id}/status`. Template criado direto no gerenciador da Meta entra na Arara com `POST /v1/templates/sync`.

## Pausa por qualidade

Mesmo aprovado, um template pode ser **pausado** pela Meta quando recebe muito feedback negativo (bloqueios, denúncias). Enquanto pausado, o envio responde `422 TEMPLATE_PAUSED`; use esse código para interromper o disparo. Para voltar a enviar, edite o conteúdo ou crie um template novo. Reenviar o mesmo texto tende a ser pausado de novo.

## Mais de um idioma

O envio escolhe o template pelo nome, sem parâmetro de idioma. Para atender em mais de um idioma, crie um template por idioma com nomes diferentes, por exemplo `pedido_confirmado` (`pt_BR`) e `pedido_confirmado_en` (`en_US`).

## Quantidade de templates

Os planos atuais (Essencial, Voo e Primeira Classe) não limitam a quantidade de templates.
