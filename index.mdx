Com a Arara você envia e recebe mensagens de WhatsApp oficial pela API, com SDKs, CLI e MCP.

## Envie uma mensagem

Com plano assinado, número conectado, um template aprovado e saldo na carteira, o envio é uma chamada. Troque `+5511999999999` pelo seu número de WhatsApp e `pedido_confirmado` pelo nome do seu template:

```bash
curl -X POST https://api.ararahq.com/v1/messages \
  -H "Authorization: Bearer $ARARA_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "receiver": "+5511999999999",
    "templateName": "pedido_confirmado",
    "templateVariables": ["João", "12345"]
  }'
```
