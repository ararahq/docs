Na Arara, links curtos saem em `https://ararahq.com/l/{code}`. Cada acesso registra um clique e redireciona pro destino. Há três formas de gerar esses links:

| Forma | Destino | Como cria |
|---|---|---|
| **Smart Link de WhatsApp** | `wa.me` do seu número, com texto inicial opcional | `POST /v1/smart-links/whatsapp` |
| **Link de mensagem** | Qualquer URL, um link por mensagem enviada | Botão `SMART_LINK` no template ou URL passada como variável |
| **Link avulso** | Qualquer URL | Dashboard, em **Links** |

O clique registra IP, user agent, referer e país (quando disponível). Links de mensagem ficam associados à mensagem, e por isso ao destinatário e à campanha. O redirecionamento não adiciona parâmetros na URL de destino.

## Smart Link de WhatsApp

Um link fixo que abre conversa com o seu número. Serve pra bio, anúncio, QR Code em material impresso.

```bash
curl -X POST https://api.ararahq.com/v1/smart-links/whatsapp \
  -H "Authorization: Bearer ara_live_xxx" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Bio do Instagram",
    "phoneNumber": "+5511999999999",
    "defaultText": "Oi, vim pelo Instagram",
    "qrCodeColor": "BLACK"
  }'
```

Resposta:

```json
{
  "id": "6f8a3c1e-2b4d-4f6a-8c9e-0a1b2c3d4e5f",
  "name": "Bio do Instagram",
  "phoneNumber": "+5511999999999",
  "defaultText": "Oi, vim pelo Instagram",
  "qrCodeColor": "BLACK",
  "code": "Ab12Cd",
  "shortUrl": "https://ararahq.com/l/Ab12Cd",
  "createdAt": "2026-09-15T10:00:00Z",
  "clicks": 0
}
```

- `name` e `phoneNumber` são obrigatórios. `qrCodeColor` default `BLACK`.
- Cada número tem um único Smart Link por organização. Criar outro pro mesmo número falha.
- Quem acessa `shortUrl` é redirecionado pra `https://wa.me/{numero}?text={defaultText}`.

| Endpoint | Função |
|---|---|
| `GET /v1/smart-links/whatsapp?page=0&size=50` | Lista paginada `{ data, pagination }`, com `clicks` por link |
| `PUT /v1/smart-links/whatsapp/{id}` | Atualiza `name`, `defaultText` e `qrCodeColor` (o número não muda) |
| `GET /v1/smart-links/whatsapp/{id}/stats` | `{ linkId, totalClicks }` |

## Botão SMART_LINK em templates

Crie o template com um botão do tipo `SMART_LINK` e a URL de destino:

```bash
curl -X POST https://api.ararahq.com/v1/templates \
  -H "Authorization: Bearer ara_live_xxx" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "produto_quente",
    "category": "MARKETING",
    "language": "pt_BR",
    "body": "Oi {{1}}, separei essa camiseta básica pra você. Toque pra ver.",
    "samples": { "1": "João" },
    "buttons": [
      {
        "type": "SMART_LINK",
        "text": "Ver produto",
        "url": "https://meusite.com.br/produto/camiseta-basica"
      }
    ]
  }'
```

A Arara registra o botão na Meta como botão de URL `https://ararahq.com/l/{{n}}`. A cada envio, cria um link curto novo pra aquela mensagem e preenche o código no botão.

No envio, dois campos opcionais de `POST /v1/messages` controlam o destino:

| Campo | Efeito |
|---|---|
| `smartLinkUrl` | Substitui a URL cadastrada no botão só nesta mensagem |
| `smartLinkParam` | Adiciona `slp={valor}` na URL de destino (ex.: id do pedido ou do cliente) |

```bash
curl -X POST https://api.ararahq.com/v1/messages \
  -H "Authorization: Bearer ara_live_xxx" \
  -H "Content-Type: application/json" \
  -d '{
    "receiver": "whatsapp:+5511999999999",
    "templateName": "produto_quente",
    "templateVariables": ["João"],
    "smartLinkUrl": "https://meusite.com.br/produto/camiseta-basica?utm_source=whatsapp",
    "smartLinkParam": "cliente-8812"
  }'
```

`POST /v1/messages/batch` aceita `smartLinkUrl` e `smartLinkParam` por item.

## URLs em variáveis e mensagens de sessão

- Variável de template que começa com `http` é trocada por um link curto `https://ararahq.com/l/{code}` no envio.
- Em mensagem de sessão (texto livre dentro da janela de 24h), toda URL no `body` é encurtada.

## Onde ver os cliques

O dashboard, em **Links**, junta links avulsos e links nascidos de campanha com a contagem de cliques. Pela API com chave `ara_live_`, a contagem está disponível pros Smart Links de WhatsApp (`clicks` e `/stats`).
