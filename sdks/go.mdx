```bash
go get github.com/ararahq/arara-go-sdk@main
```

O módulo ainda **não tem tag de release**: o `go get` resolve uma pseudo-versão do último commit da `main` (hoje `v0.0.0-20260716035048-88895cf1cf93`). Fixe essa versão no seu `go.mod` para builds reprodutíveis.

Requer Go 1.22+. Sem dependências externas (`net/http`, `encoding/json`, `context`).

## Setup

```go
import (
    "os"
    "time"

    arara "github.com/ararahq/arara-go-sdk"
)

client, err := arara.NewClient(
    os.Getenv("ARARA_API_KEY"),
    arara.WithBaseURL("https://api.ararahq.com"), // opcional, este é o default
    arara.WithTimeout(15*time.Second),            // opcional, default 10s
    arara.WithMaxRetries(3),                      // opcional, default 3
)
if err != nil {
    log.Fatal(err) // apiKey vazia
}
```

`arara.WithHTTPClient(hc)` substitui o `*http.Client` inteiro (transporte e timeout).

## Recursos disponíveis

Todo método recebe `context.Context` como primeiro argumento.

| Recurso | Acesso | Métodos |
|---|---|---|
| Messages | `client.Messages` | `Send` |
| Templates | `client.Templates` | `List`, `Create`, `Get`, `GetStatus`, `Delete` |
| Campaigns | `client.Campaigns` | `Create`, `List`, `Estimate`, `Get`, `Cancel` |
| Contacts | `client.Contacts` | `List`, `ImportBatch`, `Stats`, `ReactivationCandidates`, `ListTags`, `Get`, `Update`, `Messages` |
| Conversations | `client.Conversations` | `List`, `LeadStats`, `Messages`, `Reply`, `UpdateStatus`, `WindowStatus` |
| Wallet | `client.Wallet` | `Transactions`, `GetAutoRecharge`, `UpdateAutoRecharge` |
| Numbers | `client.Numbers` | `List`, `Update`, `Delete`, `Request`, `ListRequests`, `Sync`, `Warming` |
| Smart links | `client.SmartLinks` | `Create`, `Update`, `List`, `Stats` |
| Users | `client.Users` | `GetMe`, `Update` |
| Organizations | `client.Organizations` | `GetWebhook`, `UpdateWebhook` |
| API Keys | `client.APIKeys` | `List`, `Create` (ver limitações) |

## Enviar mensagem

```go
ctx := context.Background()

resp, err := client.Messages.Send(ctx, &arara.SendMessageRequest{
    Receiver:     "whatsapp:+5511999999999",
    TemplateName: "confirmacao_pedido",
    TemplateVariables: []string{
        "https://meusite.com/nota/123.pdf", // header (mídia opcional)
        "João",                              // {{1}}
        "ARA-12345",                         // {{2}}
    },
}, arara.SendOptions{IdempotencyKey: "pedido-12345"})
if err != nil {
    log.Fatal(err)
}

fmt.Println(resp.ID, resp.Status) // ara_msg_... e status inicial
```

**Mensagem de sessão (texto livre, dentro da janela de 24h):**

```go
_, err = client.Messages.Send(ctx, &arara.SendMessageRequest{
    Receiver: "whatsapp:+5511999999999",
    Body:     "Oi! Vi sua dúvida e respondo já já.",
})
```

`SendOptions` é opcional. Repetir a mesma `IdempotencyKey` devolve a mensagem original. A API não compara o corpo nem expira a chave: com destinatário ou variáveis diferentes, a resposta continua sendo a mensagem original. O SDK não tem método para consultar a mensagem depois; use `GET /v1/messages/{id}` direto ou o webhook `message.status_updated`.

## Templates

`Get`, `GetStatus` e `Delete` recebem o **id** do template (UUID), não o nome.

```go
tpl, err := client.Templates.Create(ctx, &arara.CreateTemplateRequest{
    Name:     "promo_natal",
    Category: "MARKETING",
    Language: "pt_BR",
    Body:     "Oi {{1}}, oferta de Natal: {{2}}% off até {{3}}.",
    Samples:  map[string]string{"1": "João", "2": "30", "3": "sexta"},
})
if err != nil {
    log.Fatal(err)
}

status, err := client.Templates.GetStatus(ctx, tpl.ID)
if err == nil {
    fmt.Println(status.Status) // PENDING, APPROVED, REJECTED...
}
```

## Campanhas

`Create` gera um `Idempotency-Key` (UUID v4) quando você não passa um. Passe o seu para que um retry do seu lado não crie campanha duplicada.

```go
campaign, err := client.Campaigns.Create(ctx, &arara.CampaignRequest{
    Name:         "blackfriday-2026",
    TemplateName: "bf_oferta_geral",
    Contacts: []arara.CampaignContactRequest{
        {To: "whatsapp:+5511999999999", Variables: []string{"João", "30"}},
        {To: "whatsapp:+5511888888888", Variables: []string{"Maria", "25"}},
    },
}, arara.CampaignCreateOptions{IdempotencyKey: "bf-2026-lote-1"})
if err != nil {
    log.Fatal(err)
}

detail, err := client.Campaigns.Get(ctx, campaign.ID)
```

## Erros

Toda falha devolve `*arara.Error`:

```go
import "errors"

_, err := client.Messages.Send(ctx, req)
var apiErr *arara.Error
if errors.As(err, &apiErr) {
    fmt.Println(apiErr.StatusCode, apiErr.Code, apiErr.Message, apiErr.Details)
    if apiErr.StatusCode == 429 && apiErr.RetryAfter != nil {
        fmt.Println("tente de novo em", *apiErr.RetryAfter, "segundos")
    }
}
```

| Campo | Conteúdo |
|---|---|
| `StatusCode` | Status HTTP. Zero em falha de rede. |
| `Code` | `error.code` da API. `NETWORK_ERROR`, `DECODE_ERROR`, `CONTEXT_CANCELED` ou `UNKNOWN_ERROR` quando não veio da API. |
| `Message` | `error.message` da API. |
| `Details` | `error.details` da API. |
| `RetryAfter` | Segundos do header `Retry-After`, quando houver. |

A API responde 403 (não 401) para chave inválida. Lista de códigos em [Erros](/erros).

## Retry

O SDK retenta até `WithMaxRetries` vezes em falha de rede, 429 e qualquer 5xx. Respeita `Retry-After` (até 30s); sem ele, espera 500ms e dobra a cada tentativa, até 30s. Cancelar o `context` interrompe a espera. Para desligar: `arara.WithMaxRetries(0)`.

<Warning>
  O retry reenvia `POST /v1/messages` em 5xx. Passe `SendOptions{IdempotencyKey: ...}` em todo envio.
</Warning>

## Webhooks

O SDK não tem helper de webhook. Valide `X-Arara-Signature` com `crypto/hmac` sobre `"{X-Arara-Timestamp}.{corpo cru}"` e compare com `hmac.Equal`. Detalhes em [Webhooks](/webhooks).

## Limitações conhecidas

| Método | Problema |
|---|---|
| `Templates.List` | A API responde `{ data, pagination }` e o SDK decodifica em `[]Template`: erro `DECODE_ERROR`. |
| `Templates.Get/GetStatus/Delete` | Precisam do id (UUID). Com o nome a API responde 400. |
| `APIKeys.*` | A API recusa gestão de chaves autenticada por API key (403). Crie e revogue chaves pelo dashboard. |
